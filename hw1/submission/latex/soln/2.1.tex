Please see the generated plots in Figure~\ref{fig:unicycle_xy} and
Figure~\ref{fig:unicycle_state}. The purpose of the gains and the factor
$\max(0,\cos e_\theta)$ are detailed in the following bullet points.
\begin{itemize}
    \item $k_v$: This gain provides a feedback multiplication on the velocity
    error. Thus, this gain drives the response in velocity tracking.
    \item $k_\theta$: This gain provides a feedback multiplication on the
    heading error. Thus, this gain drives the response in heading tracking.
    \item $\max(0,\cos e_\theta)$: This maximum protects against commanding a
    positive speed when the vehicle is pointed more than $\pi/2$ radians away
    from the goal. In this case, we'd rather only run our heading towards to
    target to wait until we are headed in the correct direction. Otherwise, we
    are not moving \emph{towards} the goal position.
\end{itemize}
